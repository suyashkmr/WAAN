# WAAN v2.4.6

## What changed

- Carries forward all `v2.4.5` release changes because the `v2.4.5` macOS release workflow failed and did not publish artifacts.
- Fixed a regression where Search Messages showed summary text but no message rows in common runtime paths.
- Hardened `search/resultsUi` rendering so message rows and panel-state UI fall back to deterministic DOM rendering when Vue bridge rendering is partial/unavailable.
- Added/updated tests to lock fallback + cache behavior and prevent stale blank-result regressions.
- Hardened tagged-release performance budget profile for hosted macOS runner variance:
  - Increased `release-ci` `search.keywordIndexed` threshold to `<= 10ms`.
  - Increased `release-ci` `sync.appendImmediate` threshold to `<= 650ms`.
  - Documented the updated release-ci thresholds in performance docs.
- Added Phase 8a planning tasks for purist no-fallback enforcement before Phase 9 (`docs/tasks.md`).

## Why this release matters

- Publishes the intended `v2.4.5` search-fix payload after the previous release workflow failure.
- Prevents false-negative release failures from hosted-runner perf jitter while preserving strict local perf guardrails.

## Installation / upgrade notes

- Patch release with no data migration required.
- Existing chats, saved views, and relay state remain compatible.
