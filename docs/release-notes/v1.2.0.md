# WAAN v1.2.0

## What changed

- Reworked search worker indexing for incremental builds, safer cache invalidation, and responsive cancellation handling.
- Hardened relay/chat metadata persistence paths and improved degraded-network sync behavior.
- Refactored large UI and relay modules into smaller focused units and completed remote-only chat selection flow.
- Fixed Hero section navigation active-state tracking and dark-theme "Save as PDF" output behavior.
- Added new performance/verification coverage for search indexing and chat-store write amplification.

## Why this release matters

- Search on large chats is faster and more predictable while preserving result correctness across dataset updates.
- Relay sync and metadata durability are more resilient under errors and intermittent connectivity.
- The app shell and controller wiring are easier to maintain due to modular extraction and reduced file size hotspots.

## Installation / upgrade notes

- Standard upgrade; no migration steps required.
- Tag-triggered macOS artifacts are published by `.github/workflows/macos-release.yml`.
