# WAAN v2.4.1

## What changed

- Carries forward all `v2.4.0` release changes because `v2.4.0` macOS release publishing failed in CI.
- Completed the Phase 7 Vue-first orchestration milestone for app-shell behavior and bridge lifecycle.
- Removed remaining dashboard bridge handoff to legacy activity renderers:
  - Time-of-day panel now renders from Vue-owned view models.
  - Weekday panel now renders from Vue-owned view models.
  - Hourly panel now renders from Vue-owned view models.
- Hardened search rendering reliability in Vue bridge flows:
  - Fixed cases where summary/insights appeared but message rows were missing.
  - Added safe fallback when a bridge reports handled results but does not mount rows.
  - Normalized worker payload handling to compact sparse/invalid result arrays before state storage.
- Fixed stale anomaly badge state in hourly empty-data transitions.
- Updated in-app FAQ copy for current relay control and recovery language (`Connect relay`, `Reload All Chats`, `Reconnect`, `Resync`, `Export diagnostics`).
- Updated dated release documentation to remove stale branch-divergence snapshots.
- Hardened tagged-release performance gating on hosted macOS runners:
  - Added perf budget profiles in `check:perf-budgets` (`strict` default, `release-ci` for tagged release workflow).
  - Updated `.github/workflows/macos-release.yml` to run perf gate with `WAAN_PERF_BUDGET_PROFILE=release-ci`.
  - Documented profile usage in `docs/performance-at-scale.md`.

## Why this release matters

- Publishes the intended `v2.4.0` feature/reliability payload after the previous release workflow failed.
- Delivers a stable Phase 7 cut where Vue orchestration is the primary path for migrated shell/dashboard/search/saved interactions.
- Eliminates multiple user-visible stale/empty-state regressions in search and hourly analytics.
- Reduces false-negative release failures from hosted-runner perf variance while preserving release perf guardrails.

## Installation / upgrade notes

- Patch release with no data migration.
- Existing chats/saved views remain compatible.
- Chrome/Chromium prerequisite for relay sync is unchanged.
