# WAAN v2.4.3

## What changed

- Completed Phase 8 fallback-removal hardening across migrated Vue-owned surfaces.
- Removed remaining legacy dashboard/search/saved/status fallback render and interaction paths from active runtime flow.
- Removed obsolete app-shell frontend adapter wiring (`__WAAN_VUE_FRONTEND_ADAPTER__`) and deleted its module/test.
- Removed obsolete activity fallback renderer implementations now that hourly/weekday/time-of-day rendering is Vue-owned.
- Updated architecture docs/checklists to reflect Phase 8 completion and current Vue-first runtime ownership.

## Why this release matters

- Reduces UI drift and stale-state risk from split legacy+Vue render paths by enforcing Vue-first rendering on migrated surfaces.
- Simplifies runtime/module graph for maintainability and lowers regression surface in dashboard/search/saved/status behavior.

- Existing chats, saved views, and relay state remain compatible.
