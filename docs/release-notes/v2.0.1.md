# WAAN v2.0.1

## What changed

- Added a native Electron right-click context menu for dashboard surfaces.
- Enabled standard edit actions in editable fields: Undo, Redo, Cut, Copy, Paste, Select All.
- Enabled Copy/Select All in non-editable areas and text selections.
- Added `Inspect Element` in non-packaged builds for local debugging only.

## Why this release matters

- Restores expected desktop behavior in the packaged app where right-click previously did nothing.
- Improves usability and accessibility for text interactions without changing core dashboard flows.

## Installation / upgrade notes

- Standard patch upgrade; no migration required.
- Tag-triggered macOS artifacts are published by `.github/workflows/macos-release.yml`.
