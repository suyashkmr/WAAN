# WAAN v2.1.0

## What changed

- Delivered a broad dark-mode visual overhaul across core dashboard surfaces, cards, and section shells.
- Improved layout consistency and spacing rhythm for toolbar/control rows and key panel headers.
- Fixed responsive control-strip regressions around `Loaded chats`, `Custom dates`, and `Time range`.
- Hardened Shoelace proxy and app-shell styling parity to avoid fallback inconsistencies.
- Refreshed visual snapshots and kept CI verification green after styling and layout updates.

## Why this release matters

- The app now looks more cohesive and modern in daily use, especially in dark mode.
- Primary workflows (chat selection, range filtering, section scanning) feel more stable and readable.
- Release automation remains strict with curated notes and validated tag/version matching.

## Installation / upgrade notes

- Standard minor upgrade; no data migration required.
- macOS artifacts are produced by `.github/workflows/macos-release.yml` when this tag is built.
