# WAAN v2.3.0

## What changed

- Added release-enforced performance budgets for render/search/sync proxy paths (`check:perf-budgets`) and wired the gate into tagged release CI.
- Expanded relay reliability diagnostics with explicit fallback reasons (`lastSyncPathReason`) and slow-sync operator hints in banner/progress surfaces.
- Added guided recovery actions in degraded relay states: `Reconnect`, `Resync`, and `Export diagnostics`.
- Hardened recovery behavior and state transitions:
  - `Reconnect` now performs a real restart (`stop` then `start`) when relay is already running.
  - Recovery action visibility now follows current runtime state/sync signals and avoids stale-error presentation.
  - Recovery controls now disable immediately when controls lock to prevent duplicate overlapping operations.
- Expanded release-blocking regression coverage for relay transitions, export integrity, and recovery UI behavior.

## Why this release matters

- Reduces release risk by failing fast on performance and core reliability regressions.
- Makes degraded relay sessions diagnosable and actionable in-UI without guesswork.
- Improves operator trust by ensuring recovery actions do what they claim and remain state-accurate.
