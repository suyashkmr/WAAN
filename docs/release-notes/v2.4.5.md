# WAAN v2.4.5

## What changed

- Fixed a regression where Search Messages showed summary text but no message rows in common runtime paths.
- Hardened `search/resultsUi` rendering so message rows and panel-state UI fall back to deterministic DOM rendering when Vue bridge rendering is partial/unavailable.
- Added/updated tests to lock fallback + cache behavior and prevent stale blank-result regressions.

## Why this release matters

- Restores core Search Messages usability immediately.
- Improves resilience during bridge mount timing issues so users still see results instead of an empty panel.

## Installation / upgrade notes

- Patch release with no data migration required.
- Existing chats, saved views, and relay state remain compatible.
