# WAAN v2.4.7

## What changed

- Fixed a Vue-managed Search Messages regression where result rows could disappear after loading/error-to-results transitions.
- Removed a premature manual clear of the search results container in the Vue-first render path so Vue retains ownership of the render lifecycle.
- Added regression coverage to lock loading-state to populated-results transitions and prevent future blank-list regressions.
- Continued Phase 8a no-fallback hardening and bridge-readiness enforcement for search/saved rendering flow.

## Why this release matters

- Restores reliable Search Messages rendering in the primary runtime path.
- Reduces release risk for the Vue-first no-fallback architecture by adding explicit lifecycle regression tests.

## Installation / upgrade notes

- Patch release with no data migration required.
- Existing chats, saved views, and relay state remain compatible.
