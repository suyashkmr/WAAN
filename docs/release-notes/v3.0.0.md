# WAAN v3.0.0

## What changed

- Finalized the Vue-first frontend migration for app-shell orchestration and migrated UI surfaces (search, saved views, dashboard panels, relay/status shell).
- Removed remaining legacy fallback render/event branches from active production runtime paths for migrated surfaces.
- Hardened bridge/runtime contracts and added regression coverage for Vue lifecycle, dispatcher wiring, and render-state transitions.
- Updated architecture and release documentation to reflect the Vue-owned runtime model and current release sign-off guidance.

## Why this release matters

- Marks the major-version milestone where frontend runtime ownership is Vue-first for core user flows.
- Reduces UI-state drift and duplicate-path regressions by consolidating rendering/event ownership to Vue contracts.

## Installation / upgrade notes

- Major release with frontend runtime architecture changes; backend/API contracts remain unchanged.
- Existing chats, saved views, relay data, and exports remain compatible.
