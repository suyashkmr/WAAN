# WAAN v2.0.0

## What changed

- Delivered the complete Community Catalyst UI overhaul across foundation, hero/relay story lane, search + saved views command surfaces, analytics readability, and export parity.
- Finalized PDF export theme parity for light/dark with shared color-scheme resolution and added targeted regression coverage.
- Refreshed visual baselines and added repeatable screenshot capture for phase-5 surfaces across desktop/mobile and light/dark.
- Added a workspace-aware dead-code audit (`check:dead-code`) and integrated it into `ci:verify`.
- Kept reliability and maintainability guardrails green (`check:module-size`, `check:unused-exports`, `check:circular`, full test suite, visual suite).

## Why this release matters

- The app now has a consistent, modern, and significantly more polished UI language with stronger cross-surface coherence.
- Exported reports better match in-app theme intent and readability, reducing surprise in print/PDF workflows.
- CI is stricter and safer against dead code/orphan drift without brittle false positives.

## Installation / upgrade notes

- Standard upgrade; no data migration required.
- Tag-triggered macOS artifacts are published by `.github/workflows/macos-release.yml`.
