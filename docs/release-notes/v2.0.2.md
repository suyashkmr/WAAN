# WAAN v2.0.2

## What changed

- Improved dark-mode depth rendering across shell surfaces, cards, and hero sections.
- Added stronger tactile states for dark-mode controls (buttons, segmented toggles, and panel collapse toggles).
- Upgraded atmospheric background layering with subtle directional depth and improved visual elegance.
- Added fallback definitions for new background/depth tokens in base non-initialized paths to prevent pre-init/no-JS visual regressions.
- Refreshed visual baselines for affected sections and kept full automation green.

## Why this release matters

- Dark mode now has clearer elevation and more convincing 3D hierarchy, closer to light-mode polish.
- Core actions feel more tactile and interactive in dark mode without sacrificing readability.
- First paint remains visually stable even before theme initialization.

## Installation / upgrade notes

- Standard patch upgrade; no migration required.
- Tag-triggered macOS artifacts are published by `.github/workflows/macos-release.yml`.

## Included commits

- UI depth/background polish, fallback hardening, and visual baseline refresh for dark mode.
